# Xochipilli — 键盘快捷键（正式说明）

[English](KEYS.md) | [日本語](KEYS.ja.md) | **中文**

**本文件为正式说明。** 键位表刻意保持精简：只有确实用到、缺了会难受的快捷键才会加入，
而不是因为某个键还空着。

**前提：** 文本输入获得焦点时快捷键无效。

---

## 已实现（仅已采用）

| 键 | 动作 | 备注 |
|----|------|------|
| **Space** | 播放 / 暂停 | |
| **R** | 跳到曲首 | |
| **P** | 在播放头位置打点 | 第一次打开 · 第二次关闭 |
| **K** | 从**当前框起点**播放 | 选中区间 t0 → 打开点 → 播放头下的框 → 最后一框 |
| **L** | 选中区间循环 ON/OFF | 已采用 |
| **F** | 缩放使选区落入画面 | 已采用 |
| **Tab / Shift+Tab** | 下一 / 上一区间 | 已采用 |
| **← / →** | 定位 0.1 秒 | **Shift** = 1 秒 |
| **+ / −** | 放大 / 缩小 | |
| **0** | 缩放到整轨 | |
| **Enter** | 聚焦选中区间的提示词 | **唯一会自动进入提示词的方式**（或自己点文本框）。**输入中快捷键关闭**（Del 不会删掉整段） |
| **Del / Backspace** | 删除选中区间 | |
| **⌘Z / Ctrl+Z** | 撤销 | 上一步编辑 |
| **⌘Y / Ctrl+Y**（或 **⌘⇧Z**） | 重做 | 恢复撤销 |
| 滚轮 | 波形缩放 | |
| **Shift+滚轮** | 平移 | |
| 波形双击 | **播放头移到该处** | **区间框内也可**。Alt+双击 = 显示全部 |
| 点击空白波形 | 仅定位 | 打点用 **P** |
| 点击区间框 | 选中该区间（高亮） | **不**聚焦提示词、**不**移动播放头。关闭打点同理。音乐快捷键仍可用 |

设置面板 **Esc 关闭** 属于 UI（不是本表中的编辑命令）。

## 变更规则（今后严格遵守）

1. 快捷键**建议**只写在本文件「未采用」。不写代码。  
2. **只有说了「采用」的键**才进 `app.js`。  
3. 不要只在聊天里提完就结束——必须写进本文件。  
4. i18n / 设置面板列表只展示**已实现**的键。
